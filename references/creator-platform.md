# 闲鱼创作者平台（author.goofish.com）手册

> 2026-09-20 用户提供的官方创作要求整理。平台地址：https://author.goofish.com/#/
> 与易店助手（管宝贝）互补：创作者平台管**内容/帖子**，用内容给店铺引流。

## 一、平台定位

- 闲鱼官方创作者中心，发**帖子/图文内容**的地方（不是发宝贝）
- 电脑端可访问（与圈子不同——圈子只能手机 App 发；创作者平台有网页端）
- 浏览/登录走同一 Chrome 9222 + chrome-cdp-profile

## 二、官方成长三步法

1. **发优质内容**：持续输出，质量优先
2. **立人设**：选 1-2 个感兴趣的人设相结合，主页和内容要「有人味」，不摇摆
   - 本店适用人设方向（用户背景）：宜昌本地生活服务者 + AI/数码极客
3. **跟热点**：
   - 结合创作中心「热门活动」话题
   - 结合节日时事发应景帖（如圣诞/元旦/春节）
   - 热点内容 = 更多曝光 + 更多关注

## 三、文案创作规范（官方小课堂）

1. **基础信息先行**：介绍品类关键信息（品牌/型号/配色/种类等）
   - 宠物帖 → 猫狗种类；数码帖 → 品牌型号；服务帖 → 服务范围/流程
2. **选对话题**：关联话题必须与内容同领域，获得精准粉关注
3. **正文写法**：
   - 分段！让用户读起来轻松
   - 正文要含关键词（同标题），承接标题，直接给用户想知道的方案
   - 用认知对比、感官描写、细节描写增加阅读感

## 四、内容红线（违反会被删帖/限流）

1. 🚫 不得包含网站链接、邮箱或其他联系方式
2. 🚫 不得出现营销推广信息；非企业账号不得做品牌推广
   - ⚠️ 意味着帖子里**不能写「主页有宝贝」「私聊下单」这类硬导流话术**
   - 引流只能软着来：立人设 → 内容有价值 → 用户自己点进主页
3. 🚫 不得包含恶俗、消极、敏感、色情等信息
4. 叠加适用主技能的全部商品红线（境外AI工具名/模型部署/无人机考证/代刷托管/医疗代办等）

## 五、与宝贝文案的关键差异

- 宝贝描述：转化导向，可以写价格、促单、私聊
- 创作者帖子：内容导向，**禁止价格/促销/联系方式**，靠人设和价值吸粉
- 同一个服务，两条文案线，不能互相套用

## 六、发帖自动化实操（2026-09-20 实测跑通）

- **入口**：左侧黄色「发布内容」按钮是 antd dropdown-trigger，**JS 派发 mouseover/mouseenter 才展开**（真实鼠标 click/hover 均无效），菜单项：`发帖子` / `发文章`，点击进 `#/post`
- **编辑器结构**：标题 input（≤20字，placeholder 含「标题」）+ 正文 textarea（≤1000字，placeholder 含「正文」）+ 隐藏 file input + 话题选择 + 发布按钮
- **填值**：React 受控组件，用原生 setter + dispatch input/change（同易店价格框打法）
- **传图**：CDP `DOM.setFileInputFiles` 直接喂 file input，无需弹窗
- **话题**：点「添加话题」开弹窗 → 搜索框填关键词（原生 setter）→ 点弹窗内「搜索」按钮 → 结果行找话题名叶子节点向上找行容器点「选择」；话题选流量大的（看"万人在玩"数）
- **发布**：点「发 布」按钮（注意中间有空格），成功自动跳回 #/contentManager，刷新后计数 +1
- **旧帖管理**：网页端内容管理是**只读**（点帖子只弹二维码详情，无编辑/删除按钮），旧帖编辑/删除只能手机 App：我的 → 我的帖子
