# 闲鱼运营打法手册（流量/定价/诊断）

> 来源：@Lenny 的 xianyu-service-ops（MIT 协议，原英文，已翻译提炼），2026-09-18 吸收进本技能。
> 挂载方式：可选支线——用户问「流量/没曝光/定价/竞品/怎么运营」时才读；发布执行流程不依赖本文件。
> 置信度标注：🟢 实测验证 / 🟡 建议测试 / 🔴 风险提示

## 一、闲鱼流量机制（底层认知）

- **搜索**（占成交 50%+）：双通道召回 = 倒排索引（关键词匹配）+ 语义向量（同义扩展）。标题关键词是第一入口，但不必堆砌所有近义词
- **多因子排序**：转化效率 + 相关性 + 商业规则。相关性先分 3 档，同档内按转化效率排
- **推荐**：多目标排序（点击率+转化率+互动），有「满意度闸门」——停留时长+详情页深度决定是否继续推
- 🔴 「编辑=新品加权」无官方证据，别拿这个当策略
- 🔴 「视频主图有流量倾斜」无法证实，可测试但别押注

## 二、关键词研究四步

1. 闲鱼 App 搜索框输核心词，截图下拉联想词（=真实搜索词）
2. 看「想要数」判需求热度，看已售+评价数判竞争密度
3. 拆搜索结果前 2 页里 3-5 个高销量同行的标题用词
4. 确认类目：类目错放 = 相关性直接掉档，比标题写好更重要

**关键词四类型**：核心词（流量入口，放最前）/ 意图词（精准场景，如「毕业答辩」）/ 人群词（大学生/中小商家）/ 差异词（24小时交付/3套方案）

## 三、标题三变体策略

公式：核心词 + 意图/人群词 + 差异词（有位置再补长尾词）

每次产出 3 个变体，目的明确区分：
- A 版：打核心词（流量最大、竞争最烈）
- B 版：打意图词（流量精准、转化高）
- C 版：差异化角度（切细分或拼特长）

标题硬规则：❌ 联系方式 ❌ 最/第一/100% ❌ 重复堆砌 ❌ 全角符号刷屏
（叠加本技能主文件合规红线：境外AI工具名/模型部署/批量生产/托管代刷等永久禁词）

## 四、冷启动定价阶梯

先搜同类服务前 20 个的价格取中位数：

| 阶段 | 定价 | 目的 |
|---|---|---|
| 前 10 单 | 低于中位价 20-25% | 快速攒评价 |
| 10-50 单 | 持平中位价 | 靠评价保排名 |
| 50+ 单 | 高于中位价 10-20% | 口碑溢价 |

套餐结构：引流款（拉人进门）/ 标准款（真实成交主力）/ 旗舰款（价格锚点抬身价）。

## 五、详情页六段结构（按买家决策旅程排）

1. 痛点共鸣（1-2 句戳中目标买家）
2. 服务说明（做什么+交付什么，要具体）
3. 案例展示（3-5 个真实案例，前后对比最佳——**全页最重要**）
4. 交付流程（下单→沟通→初稿→修改→交付，消除「不知道怎么买」）
5. 保障承诺（修改次数/交付周期/售后政策）
6. 行动指令（前 N 名优惠/限时价/赠品）

## 六、诊断漏斗（流量差先定位再开药）

```
曝光低   → 关键词问题（标题没匹配搜索词）或账号权重低
点击低   → 主图不吸引人 / 标题没有点击动机
咨询低   → 详情页不打动人 / 价格过高
成交低   → 话术问题 / 信任不足（评价太少）
```

问用户四个数：每天曝光多少？点击多少？咨询多少？成交多少？→ 快速定位漏斗断点。

## 七、账号权重五要素（按重要性）

1. 芝麻信用分（650+）
2. 实名认证 + 支付宝绑定（没有则无推荐资格）
3. 历史成交量 + 好评率（最核心排名信号）
4. 账号活跃度（每日登录、回复速度）
5. 商品点击率/转化率（内容质量信号）

新号冷启动：第 1-2 周养号（完善资料、每日浏览、当买家买 2-3 单）→ 第 3-4 周低价发 3-5 个品拿前 10 个好评 → 第 2-3 月优化高点击品、扩关键词覆盖 → 3 月+逐步提价扩品类。

## 八、日常运营节奏

- 发布/擦亮时间窗：早 8-9 点、午 12-13 点、晚 20-22 点
- 咨询 5 分钟内回复（🔵 响应速度是核心排名因子）
- 每周更新案例（提升详情页停留时长 → 推荐满意度信号）

## 九、竞品分析五维度

输入同行链接/截图，逐项拆：标题关键词（漏了哪些高流量词）/ 定价与套餐结构（锚点在哪）/ 主图风格（可借鉴什么）/ 核心卖点（哪些吹过头可攻击）/ 评价内容（差评暴露未满足需求）。
输出必须是**可执行的差异化切入点 + 标题/卖点调整**，不是观察报告。

## 十、主动预警（发现即说，不等用户问）

- 标题无核心词 → 立刻给优化版
- 定价低于 5 元 → 触发风控警告
- 详情页无案例 → 转化重伤，必须补
- 描述含联系方式 → 立刻标红给合规替代
- 全店只有 1 个商品 → 建议多发几个覆盖关键词
- 新号定价高于市场 → 先低价走量
- 深夜/凌晨发布 → 改到高峰时段
